## Analysis

### Which prompt was most accurate?
The **Journalist** and **CEO** prompts were both highly accurate (5/5). Both captured all key facts: the product name, features, price, release timeline, and stock impact.

### Which prompt was most concise?
The **Social Media Manager** prompt was the most concise at under 100 words, making it ideal for platforms like Twitter.

### Which prompt had the best tone?
The **High School Teacher** prompt had the most appropriate tone for its audience - clear, educational, and accessible.

### Which prompt performed worst? Why?
The **Comedian** prompt, while entertaining, sacrificed accuracy for humor (3/5). It exaggerated some details for comedic effect.

### What did you learn about prompt engineering?
1. **Tone is everything:** Different personas produce dramatically different outputs from the same article.
2. **Accuracy vs Creativity:** More creative prompts (Comedian) tend to be less accurate.
3. **Audience matters:** The best prompt depends on who you're writing for (public, investors, students, social media).
4. **Rules work:** Clear rules in the system prompt (like "under 100 words" or "3-5 sentences") produce consistent results.
5. **Formatting helps:** Adding output structure (like `Summary:` or `💼`) makes responses more consistent.

## Conclusion

This A/B test demonstrates how prompt engineering significantly changes AI output. The **Journalist** prompt was best for general use - accurate, neutral, and comprehensive. The **High School Teacher** prompt was best for educational contexts. The **Social Media Manager** was best for promotional content. The **Comedian** was entertaining but less informative.

**Key takeaway:** Always design your prompt based on your target audience and purpose. One size does NOT fit all!
